**原题链接**：[104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/description/)

**标签**：[树](https://leetcode.cn/tag/tree/) [深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [广度优先搜索](https://leetcode.cn/tag/breadth-first-search/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给定一个二叉树 `root`，返回其最大深度。
- 二叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点数。

**示例 1：**
输入：root = [3,9,20,null,null,15,7]
输出：3

**示例 2：**
输入：root = [1,null,2]
输出：2

**提示：**
- 树中节点的数量在 `[0, 10^4]` 区间内。
- `-100 <= Node.val <= 100`


**解法**
```java
/*
 * 核心算法：DFS（深度优先搜索）递归求树高。
 * 1. 若当前节点为空，说明没有子树，高度为 0。
 * 2. 分别递归计算左子树和右子树的最大深度。
 * 3. 当前节点的最大深度等于左右子树较大深度再加上当前节点这一层。
 */

/*
 * 时间复杂度：O(n)
 * 每个节点都会被递归访问一次，其中 n 为二叉树节点数。
 *
 * 空间复杂度：O(h)
 * 递归调用栈深度取决于树高 h；最坏情况下树退化为链表，空间复杂度为 O(n)。
 */
public int maxDepth(TreeNode root) {
	if (root == null)
		return 0;

	int l = maxDepth(root.left), r = maxDepth(root.right);
	return Math.max(l, r) + 1;
}
```
