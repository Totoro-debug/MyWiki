**原题链接**：[236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

**标签**：[树](https://leetcode.cn/tag/tree/) [深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给定一个二叉树，找到该树中两个指定节点的最近公共祖先。
- 最近公共祖先的定义为：对于有根树 `T` 的两个节点 `p`、`q`，最近公共祖先表示为一个节点 `x`，满足 `x` 是 `p`、`q` 的祖先且 `x` 的深度尽可能大。（一个节点也可以是它自己的祖先）

**示例 1：**
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3。

**示例 2：**
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和节点 4 的最近公共祖先是节点 5。因为根据定义，最近公共祖先节点可以为节点本身。

**示例 3：**
输入：root = [1,2], p = 1, q = 2
输出：1

**提示：**
- 树中节点数目在范围 `[2, 10^5]` 内
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` 互不相同
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中


**解法**
```java
/*
 * 核心算法：DFS（后序遍历）递归搜索。
 * 1. 如果当前节点为空，或当前节点就是 p / q，则直接返回当前节点，表示在当前子树中找到了目标。
 * 2. 分别递归搜索左右子树，判断 p 和 q 分布在哪些子树中。
 * 3. 如果左右子树都返回非空，说明 p 和 q 分别位于当前节点两侧，当前节点就是最近公共祖先。
 * 4. 如果只有一侧返回非空，说明两个目标节点都在这一侧，向上返回该侧结果。
 */

/*
 * 时间复杂度：O(n)
 * 最坏情况下需要遍历整棵二叉树的所有节点，其中 n 为树中节点数。
 *
 * 空间复杂度：O(h)
 * 递归调用栈深度取决于二叉树高度 h；最坏情况下树退化为链表，空间复杂度为 O(n)。
 */
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
	if (root == null || root == p || root == q)
		return root;

	TreeNode l = lowestCommonAncestor(root.left, p, q), r = lowestCommonAncestor(root.right, p, q);
	if (l == null)
		return r;
	if (r == null)
		return l;
	return root;
}
```
