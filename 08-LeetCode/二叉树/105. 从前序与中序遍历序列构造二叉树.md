**原题链接**：[105. 从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/)

**标签**：[树](https://leetcode.cn/tag/tree/) [数组](https://leetcode.cn/tag/array/) [哈希表](https://leetcode.cn/tag/hash-table/) [分治](https://leetcode.cn/tag/divide-and-conquer/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的先序遍历，`inorder` 是同一棵树的中序遍历，请构造二叉树并返回其根节点。

**示例 1：**
输入：preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出：[3,9,20,null,null,15,7]

**示例 2：**
输入：preorder = [-1], inorder = [-1]
输出：[-1]

**提示：**
- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 均无重复元素
- `inorder` 均出现在 `preorder`
- `preorder` 保证为二叉树的前序遍历序列
- `inorder` 保证为二叉树的中序遍历序列


**解法**
```java
/*
 * 核心算法：递归分治构造二叉树。
 * 1. 前序遍历的第一个元素一定是当前子树根节点。
 * 2. 在线性扫描中序遍历中找到根节点位置，将中序区间切分为左子树和右子树。
 * 3. 根据左、右子树节点数量，同步切分前序遍历区间，并递归构造左右子树。
 * 4. 递归边界是当前前序区间为空，此时说明没有节点，返回 null。
 */

/*
 * 时间复杂度：O(n^2)
 * 每个节点都会作为根节点递归处理一次；当前写法每次通过 findroot 在线性扫描中序数组查找根节点，最坏情况下会产生 n + (n - 1) + ... + 1 次查找。
 *
 * 空间复杂度：O(h)
 * 额外空间主要来自递归调用栈，h 为二叉树高度；最坏情况下树退化为链表时为 O(n)，平衡树时为 O(log n)。不计入返回结果二叉树本身占用的空间。
 */
public TreeNode buildTree(int[] preorder, int[] inorder) {
	return build(preorder, inorder, 0, preorder.length - 1, 0, preorder.length - 1);
}

TreeNode build(int[] preorder, int[] inorder, int pl, int pr, int il, int ir) {
	if (pl > pr)
		return null;

	int rootval = preorder[pl], rootidx = findroot(inorder, rootval, il);
	int lcnt = rootidx - il, rcnt = ir - rootidx;
	TreeNode node = new TreeNode(rootval);
	node.left = build(preorder, inorder, pl + 1, pl + lcnt, il, rootidx - 1);
	node.right = build(preorder, inorder, pr - rcnt + 1, pr, rootidx + 1, ir);
	return node;
}

int findroot(int[] inorder, int root, int l) {
	int idx = l;
	while (inorder[idx] != root)
		idx++;
	return idx;
}
```
