**原题链接**：[98. 有效的二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/description/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[树](https://leetcode.cn/tag/tree/) [深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [二叉搜索树](https://leetcode.cn/tag/binary-search-tree/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给你一个二叉树的根节点 `root`，判断其是否是一个有效的二叉搜索树。
- 有效二叉搜索树定义如下：
  - 节点的左子树只包含小于当前节点的数。
  - 节点的右子树只包含大于当前节点的数。
  - 所有左子树和右子树自身必须也是二叉搜索树。

**示例 1：**
输入：root = [2,1,3]
输出：true

**示例 2：**
输入：root = [5,1,4,null,null,3,6]
输出：false
解释：根节点的值是 5，但是右子节点的值是 4。

**提示：**
- 树中节点数目范围在 `[1, 10^4]` 内
- `-2^31 <= Node.val <= 2^31 - 1`


**解法**
```java
/*
 * 核心算法：中序遍历 + stack 迭代
 * 1. 二叉搜索树的中序遍历结果必须严格递增。
 * 2. 使用栈模拟递归中序遍历，按“左子树 -> 当前节点 -> 右子树”的顺序访问节点。
 * 3. 用 preval 记录上一个访问节点的值，如果当前值不大于前一个值，说明不是有效二叉搜索树。
 */

/*
 * 时间复杂度：O(n)
 * 每个节点最多入栈、出栈各一次，其中 n 为二叉树节点数。
 *
 * 空间复杂度：O(n)
 * 栈空间取决于树的高度，最坏情况下二叉树退化为链表，高度为 n。
 */
public boolean isValidBST(TreeNode root) {
	Deque<TreeNode> stack = new LinkedList<>();
	Integer preval = null;
	while (!stack.isEmpty() || root != null) {
		while (root != null) {
			stack.push(root);
			root = root.left;
		}

		root = stack.pop();
		if (preval != null && preval >= root.val)
			return false;
		preval = root.val;
		root = root.right;
	}

	return true;
}
```
