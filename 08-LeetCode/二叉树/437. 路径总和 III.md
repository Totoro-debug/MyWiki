**原题链接**：[437. 路径总和 III](https://leetcode.cn/problems/path-sum-iii/description/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[树](https://leetcode.cn/tag/tree/) [深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给定一个二叉树的根节点 `root`，和一个整数 `targetSum`，求该二叉树里节点值之和等于 `targetSum` 的路径的数目。
- 路径不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。

**示例 1：**
输入：root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
输出：3
解释：和等于 8 的路径有 3 条。

**示例 2：**
输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：3

**提示：**
- 二叉树的节点个数的范围是 `[0, 1000]`
- `-10^9 <= Node.val <= 10^9`
- `-1000 <= targetSum <= 1000`


**解法**
```java
/*
 * 核心算法：DFS 回溯 + 前缀和计数。
 * 1. 从根节点向下遍历时，sum 表示当前路径从根到当前节点的前缀和。
 * 2. 若存在某个祖先前缀和 pre，使得 sum - pre == target，则该祖先之后到当前节点形成一条合法路径。
 * 3. 用 map 记录当前递归路径上各个前缀和出现次数，访问当前节点时累加 map[sum - target]。
 * 4. 递归进入左右子树前加入当前前缀和，退出当前节点时回溯删除，保证 map 只表示当前路径。
 */

/*
 * 时间复杂度：O(n)
 * 每个节点只会被 DFS 访问一次，每次访问只进行常数次哈希表查询和更新，n 为二叉树节点数。
 *
 * 空间复杂度：O(n)
 * 哈希表最多记录当前路径上的前缀和，递归调用栈最多为树高 h；最坏情况下树退化为链表，二者均可能达到 O(n)。
 */
HashMap<Long, Integer> map = new HashMap<>();
int ans = 0;

public int pathSum(TreeNode root, int targetSum) {
	map.put(0L, 1);
	dfs(root, 0, targetSum);
	return ans;
}

void dfs(TreeNode root, long sum, long target) {
	if (root == null)
		return;

	sum += root.val;
	ans += map.getOrDefault(sum - target, 0);
	map.put(sum, map.getOrDefault(sum, 0) + 1);
	dfs(root.left, sum, target);
	dfs(root.right, sum, target);
	map.put(sum, map.get(sum) - 1);
}
```
