**原题链接**：[199. 二叉树的右视图](https://leetcode.cn/problems/binary-tree-right-side-view/description/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[树](https://leetcode.cn/tag/tree/) [深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [广度优先搜索](https://leetcode.cn/tag/breadth-first-search/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给定一个二叉树的根节点 `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

**示例 1：**
输入：root = [1,2,3,null,5,null,4]
输出：[1,3,4]

**示例 2：**
输入：root = [1,null,3]
输出：[1,3]

**示例 3：**
输入：root = []
输出：[]

**提示：**
- 二叉树的节点个数的范围是 `[0, 100]`
- `-100 <= Node.val <= 100`


**解法**
```java
/*
 * 核心算法：BFS（广度优先搜索）层序遍历。
 * 1. 使用队列按层遍历二叉树，保证每一层的节点会连续出队处理。
 * 2. 每轮先记录当前队列长度 size，只处理当前层的这些节点。
 * 3. 当前层从左到右遍历，最后一次出队的节点就是从右侧能看到的节点，将其加入答案。
 */

/*
 * 时间复杂度：O(n)
 * 每个节点最多入队、出队各一次，其中 n 为二叉树节点数。
 *
 * 空间复杂度：O(n)
 * 队列在最坏情况下可能存储一层节点，答案列表最多存储树的高度个节点值。
 */
public List<Integer> rightSideView(TreeNode root) {
	if (root == null)
		return List.of();

	List<Integer> ans = new LinkedList<>();
	Deque<TreeNode> queue = new LinkedList<>();
	queue.add(root);
	while (!queue.isEmpty()) {
		int size = queue.size();
		TreeNode node = null;
		while (size-- > 0) {
			node = queue.poll();
			if (node.left != null)
				queue.add(node.left);
			if (node.right != null)
				queue.add(node.right);
		}
		ans.add(node.val);
	}
	return ans;
}
```
