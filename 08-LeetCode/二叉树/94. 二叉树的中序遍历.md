**标签**：[栈](https://leetcode.cn/tag/stack/) [树](https://leetcode.cn/tag/tree/) [深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给定一个二叉树的根节点 `root`，返回它的中序遍历。

**示例 1：**
输入：root = [1,null,2,3]
输出：[1,3,2]

**示例 2：**
输入：root = []
输出：[]

**示例 3：**
输入：root = [1]
输出：[1]

**提示：**
- 树中节点数目在范围 `[0, 100]` 内
- `-100 <= Node.val <= 100`

**进阶：**
- 递归算法很简单，你可以通过迭代算法完成吗？


**解法**
```java
/*
 * 核心算法：DFS（深度优先搜索）递归中序遍历。
 * 1. 中序遍历的访问顺序是：左子树 -> 当前节点 -> 右子树。
 * 2. 递归函数负责遍历以当前节点为根的子树，遇到空节点时直接返回。
 * 3. 先递归访问左子树，再记录当前节点值，最后递归访问右子树。
 */

/*
 * 时间复杂度：O(n)
 * 每个节点都会被访问一次，其中 n 为二叉树节点数。
 *
 * 空间复杂度：O(n)
 * 递归调用栈在最坏情况下会达到树的高度 n；结果列表也需要保存 n 个节点值。
 */
public List<Integer> inorderTraversal(TreeNode root) {
	List<Integer> ans = new LinkedList<>();
	dfs(root, ans);
	return ans;
}

void dfs(TreeNode root, List<Integer> list) {
	if (root == null)
		return;
	dfs(root.left, list);
	list.add(root.val);
	dfs(root.right, list);
}
```
