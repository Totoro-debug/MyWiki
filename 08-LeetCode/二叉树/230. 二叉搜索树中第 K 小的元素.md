**标签**：[树](https://leetcode.cn/tag/tree/) [深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [二叉搜索树](https://leetcode.cn/tag/binary-search-tree/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给定一个二叉搜索树的根节点 `root`，和一个整数 `k`，请你设计一个算法查找其中第 `k` 小的元素（从 1 开始计数）。

**示例 1：**
输入：root = [3,1,4,null,2], k = 1
输出：1

**示例 2：**
输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：3

**提示：**
- 树中的节点数为 `n`
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`

**进阶：**
- 如果二叉搜索树经常被修改（插入 / 删除操作）并且你需要频繁地查找第 `k` 小的值，你将如何优化算法？


**解法**
```java
/*
 * 核心算法：中序遍历 + 栈模拟递归。
 * 1. 二叉搜索树的中序遍历结果按从小到大排列。
 * 2. 使用栈迭代模拟中序遍历，按照“左子树 -> 当前节点 -> 右子树”的顺序访问节点。
 * 3. 每访问一个节点就递减 k，当 k 减到 0 时，当前节点就是第 k 小的元素。
 */

/*
 * 时间复杂度：O(h + k)
 * 其中 h 为树的高度。算法先走到最左侧需要 O(h)，随后最多弹出并访问 k 个节点。
 * 最坏情况下 k = n，因此时间复杂度为 O(n)。
 *
 * 空间复杂度：O(h)
 * 栈中最多保存从根节点到当前节点路径上的节点，空间取决于树高。
 * 最坏情况下二叉树退化为链表，空间复杂度为 O(n)。
 */
public int kthSmallest(TreeNode root, int k) {
	Deque<TreeNode> stack = new LinkedList<>();
	while (root != null || !stack.isEmpty()) {
		while (root != null) {
			stack.push(root);
			root = root.left;
		}
		root = stack.pop();
		if (--k == 0)
			return root.val;
		root = root.right;
	}
	return 0;
}
```
