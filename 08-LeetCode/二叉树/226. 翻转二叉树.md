**原题链接**：[226. 翻转二叉树](https://leetcode.cn/problems/invert-binary-tree/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[树](https://leetcode.cn/tag/tree/) [深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [广度优先搜索](https://leetcode.cn/tag/breadth-first-search/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。

**示例 1：**
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]

**示例 2：**
输入：root = [2,1,3]
输出：[2,3,1]

**示例 3：**
输入：root = []
输出：[]

**提示：**
- 树中节点数目范围在 `[0, 100]` 内。
- `-100 <= Node.val <= 100`


**解法**
```java
/*
 * 核心算法：DFS（深度优先搜索）递归翻转二叉树。
 * 1. 若当前节点为空，直接返回空节点，作为递归终止条件。
 * 2. 保存当前节点的左子树，递归翻转右子树后放到左侧。
 * 3. 再递归翻转原左子树并放到右侧，完成当前节点左右子树交换。
 */

/*
 * 时间复杂度：O(n)
 * 每个节点都会被访问并交换一次，其中 n 为二叉树节点数。
 *
 * 空间复杂度：O(h)
 * 递归调用栈深度取决于树高 h；最坏情况下树退化为链表，空间复杂度为 O(n)。
 */
public TreeNode invertTree(TreeNode root) {
	if (root == null)
		return root;

	TreeNode left = root.left;
	root.left = invertTree(root.right);
	root.right = invertTree(left);
	return root;
}
```
