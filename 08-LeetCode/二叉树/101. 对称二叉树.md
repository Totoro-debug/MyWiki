**原题链接**：[101. 对称二叉树](https://leetcode.cn/problems/symmetric-tree/description/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[树](https://leetcode.cn/tag/tree/) [深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [广度优先搜索](https://leetcode.cn/tag/breadth-first-search/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给你一个二叉树的根节点 `root`，检查它是否轴对称。

**示例 1：**
输入：root = [1,2,2,3,4,4,3]
输出：true

**示例 2：**
输入：root = [1,2,2,null,3,null,3]
输出：false

**提示：**
- 树中节点数目在范围 `[1, 1000]` 内
- `-100 <= Node.val <= 100`

**进阶：**
- 你可以运用递归和迭代两种方法解决这个问题吗？


**解法**
```java
/*
 * 核心算法：DFS（深度优先搜索）递归判断镜像对称。
 * 1. 对称二叉树要求根节点的左子树和右子树互为镜像。
 * 2. 每次递归同时比较两个镜像位置的节点：左子树的左节点对应右子树的右节点，左子树的右节点对应右子树的左节点。
 * 3. 若两个节点同时为空，则当前镜像位置对称；若只有一个为空或节点值不同，则不对称。
 */

/*
 * 时间复杂度：O(n)
 * 每个节点最多被访问一次，其中 n 为二叉树节点数。
 *
 * 空间复杂度：O(n)
 * 递归调用栈取决于树高，最坏情况下二叉树退化为链表，递归深度为 n。
 */
public boolean isSymmetric(TreeNode root) {
	if (root == null)
		return true;
	return isMirror(root.left, root.right);
}

boolean isMirror(TreeNode l, TreeNode r) {
	if (l == null || r == null)
		return l == null && r == null;

	return l.val == r.val && isMirror(l.left, r.right) && isMirror(l.right, r.left);
}
```
