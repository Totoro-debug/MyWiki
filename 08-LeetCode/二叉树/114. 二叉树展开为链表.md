**原题链接**：[114. 二叉树展开为链表](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/description/)

**标签**：[栈](https://leetcode.cn/tag/stack/) [树](https://leetcode.cn/tag/tree/) [深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [链表](https://leetcode.cn/tag/linked-list/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给你二叉树的根结点 `root`，请你将它展开为一个单链表：
  - 展开后的单链表应该同样使用 `TreeNode`，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null`。
  - 展开后的单链表应该与二叉树先序遍历顺序相同。

**示例 1：**
输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]

**示例 2：**
输入：root = []
输出：[]

**示例 3：**
输入：root = [0]
输出：[0]

**提示：**
- 树中结点数在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`

**进阶：**
- 你可以使用原地算法（`O(1)` 额外空间）展开这棵树吗？


**解法**
```java
/*
 * 核心算法：DFS 后序返回尾节点 + 原地指针重连。
 * 1. 对每个节点先保存原左子树和原右子树，避免修改指针后丢失子树入口。
 * 2. 将当前节点的 left 置空；若存在左子树，则把左子树接到 right，并递归展开左子树，得到展开后链表的尾节点。
 * 3. 若存在原右子树，则把它接到当前尾节点之后，再递归展开右子树，最终返回整段链表的尾节点。
 * 4. 整体展开顺序等价于二叉树的先序遍历：根 -> 左 -> 右。
 */

/*
 * 时间复杂度：O(n)
 * 每个节点只会被 dfs 访问一次，并进行常数次指针修改，其中 n 为二叉树节点数。
 *
 * 空间复杂度：O(h)
 * 额外空间主要来自递归调用栈，h 为树高；最坏情况下退化为链表时为 O(n)，平衡树时为 O(log n)。
 */
public void flatten(TreeNode root) {
	if (root == null)
		return;
	dfs(root);
}

TreeNode dfs(TreeNode root) {
	TreeNode left = root.left, right = root.right, tail = root;
	root.left = null;
	if (left != null) {
		tail.right = left;
		tail = dfs(left);
	}
	if (right != null) {
		tail.right = right;
		tail = dfs(right);
	}
	return tail;
}
```
