**原题链接**：[102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/description/)

**标签**：[树](https://leetcode.cn/tag/tree/) [广度优先搜索](https://leetcode.cn/tag/breadth-first-search/) [二叉树](https://leetcode.cn/tag/binary-tree/)

**描述**：

- 给你二叉树的根节点 `root`，返回其节点值的层序遍历。（即逐层地，从左到右访问所有节点）。

**示例 1：**
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]

**示例 2：**
输入：root = [1]
输出：[[1]]

**示例 3：**
输入：root = []
输出：[]

**提示：**
- 树中节点数目在范围 `[0, 2000]` 内
- `-1000 <= Node.val <= 1000`


**解法**
```java
/*
 * 核心算法：BFS（广度优先搜索）层序遍历。
 * 1. 使用队列保存当前待访问的节点，保证节点按从上到下、从左到右的顺序出队。
 * 2. 每轮先记录当前队列长度 n，表示这一层的节点数量，只处理这 n 个节点。
 * 3. 访问当前层节点时，将其左右子节点依次入队，供下一轮处理。
 */

/*
 * 时间复杂度：O(n)
 * 每个节点只会入队、出队并访问一次，其中 n 为二叉树节点数。
 *
 * 空间复杂度：O(n)
 * 队列在最坏情况下可能存储一整层节点，结果列表也需要保存所有节点值。
 */
public List<List<Integer>> levelOrder(TreeNode root) {
	if (root == null)
		return List.of();

	List<List<Integer>> ans = new LinkedList<>();
	Deque<TreeNode> queue = new LinkedList<>();
	queue.offer(root);
	while (!queue.isEmpty()) {
		int n = queue.size();
		List<Integer> list = new ArrayList<>(n);
		while (n-- > 0) {
			TreeNode node = queue.poll();
			list.add(node.val);
			if (node.left != null)
				queue.offer(node.left);
			if (node.right != null)
				queue.offer(node.right);
		}
		ans.add(list);
	}
	return ans;
}
```
