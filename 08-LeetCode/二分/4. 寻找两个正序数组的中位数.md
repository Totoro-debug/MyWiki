**原题链接**：[4. 寻找两个正序数组的中位数](https://leetcode.cn/problems/median-of-two-sorted-arrays/)

**标签**：[数组](https://leetcode.cn/tag/array/) [二分查找](https://leetcode.cn/tag/binary-search/) [分治](https://leetcode.cn/tag/divide-and-conquer/)

**描述**：

- 给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。
- 请你找出并返回这两个正序数组的中位数。
- 算法的时间复杂度应该为 `O(log (m+n))`。

**示例 1：**
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3]，中位数 2。

**示例 2：**
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4]，中位数 (2 + 3) / 2 = 2.5。

**提示：**
- `nums1.length == m`
- `nums2.length == n`
- `0 <= m <= 1000`
- `0 <= n <= 1000`
- `1 <= m + n <= 2000`
- `-10^6 <= nums1[i], nums2[i] <= 10^6`



**解法**
```java
public double findMedianSortedArrays(int[] nums1, int[] nums2) {
	int m = nums1.length, n = nums2.length, k = (m + n) / 2;
	if ((k << 1) == (m + n))
		return (getK(nums1, nums2, m, n, k) + getK(nums1, nums2, m, n, k + 1)) / 2.0;
	else
		return getK(nums1, nums2, m, n, k + 1) * 1.0;
}

int getK(int[] nums1, int[] nums2, int m, int n, int k) {
	int mid, mid1, mid2;
	int i = 0, j = 0;
	while (i < m && j < n) {
		if (k == 1)
			return Math.min(nums1[i], nums2[j]);
		mid = k >> 1;
		mid1 = Math.min(m, i + mid);
		mid2 = Math.min(n, j + mid);
		if (nums1[mid1 - 1] < nums2[mid2 - 1]) {
			k -= mid1 - i;
			i = mid1;
		} else {
			k -= mid2 - j;
			j = mid2;
		}
	}

	return i >= m ? nums2[j + k - 1] : nums1[i + k - 1];
}
```
