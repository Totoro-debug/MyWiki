**原题链接**：[76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[哈希表](https://leetcode.cn/tag/hash-table/)[字符串](https://leetcode.cn/tag/string/)[滑动窗口](https://leetcode.cn/tag/sliding-window/)

**描述**：给你一个字符串 `s`、一个字符串 `t`。返回 `s` 中涵盖 `t` 所有字符的最小子串。如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""`。

注意：
- 对于 `t` 中重复字符，我们寻找的子字符串中该字符数量必须不少于 `t` 中该字符数量。
- 如果 `s` 中存在这样的子串，我们保证它是唯一的答案。

**示例 1:**
输入: s = "ADOBECODEBANC", t = "ABC"
输出: `"BANC"`
解释: 最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

**示例 2:**
输入: s = "a", t = "a"
输出: `"a"`
解释: 整个字符串 s 是最小覆盖子串。

**示例 3:**
输入: s = "a", t = "aa"
输出: `""`
解释: t 中两个字符 'a' 均应包含在 s 的子串中，因此没有符合条件的子字符串，返回空字符串。

**提示：**
- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 105`
- `s` 和 `t` 由英文字母组成

**解法**
```java
class Solution {
    /*
     * 核心算法：滑动窗口 + 计数数组
     * 1. 用 need 记录 t 中每个字符的所需次数，用 has 记录当前窗口中的字符次数。
     * 2. 右指针 r 不断扩张窗口；当新加入字符达到需求次数时，才尝试收缩左边界。
     * 3. 收缩左边界时移除所有“超额”的字符，使当前窗口在该右边界下尽量短。
     * 4. 若窗口覆盖 t 的全部字符需求，则更新最短窗口的起点和长度。
     */
    /*
     * 时间复杂度：O(|s| * C)，固定字符集下可记为 O(|s|)
     * 说明：左右指针总移动次数为 O(|s|)；每次候选窗口调用 check 扫描常数规模字符集 C。
     *
     * 空间复杂度：O(|s| + C)
     * 说明：toCharArray 额外存储 s 的字符数组；has 和 need 两个计数数组占用固定字符集空间。
     */
    public String minWindow(String s, String t) {
        int n = s.length(), m = t.length();
        if (n < m)
            return "";

        // need 保存目标字符需求，has 保存当前滑动窗口内的字符计数。
        int[] has = new int[128], need = new int[128];
        for (char ch : t.toCharArray()) {
            need[ch]++;
        }

        char[] str = s.toCharArray();
        // l、r 表示窗口左右边界；start、min 记录当前最短覆盖子串。
        int l = 0, r = 0, start = 0, min = n + 1;
        while (r < n) {
            char ch = str[r++];
            has[ch]++;
            // 只有当前字符属于 t 且数量已达到需求时，窗口才可能形成有效覆盖。
            if (need[ch] > 0 && has[ch] >= need[ch]) {
                // 移除左侧多余字符，尽量缩短当前窗口。
                while (has[ch = str[l]] > need[ch]) {
                    has[ch]--;
                    l++;
                }

                // 窗口长度足够且所有字符需求均被覆盖时，更新答案。
                if (r - l >= m && r - l < min && check(has, need)) {
                    min = r - l;
                    start = l;
                }
            }
        }
        return min > n ? "" : s.substring(start, start + min);
    }

    boolean check(int[] has, int[] need) {
        // 题目只包含英文字母，检查 ASCII 中从 'A' 到 'z' 的相关区间即可。
        int i = 'A';
        while (i <= 'z' && has[i] >= need[i]) {
            i++;
        }
        return i > 'z';
    }
}
```
