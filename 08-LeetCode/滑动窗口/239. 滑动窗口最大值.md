**原题链接**：[239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[队列](https://leetcode.cn/tag/queue/)[数组](https://leetcode.cn/tag/array/)[滑动窗口](https://leetcode.cn/tag/sliding-window/)[单调队列](https://leetcode.cn/tag/monotonic-queue/)[堆（优先队列）](https://leetcode.cn/tag/heap-priority-queue/)

**描述**：给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只能看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回滑动窗口中的最大值。

**示例 1:**
输入: nums = `[1,3,-1,-3,5,3,6,7]`, k = `3`
输出: `[3,3,5,5,6,7]`
解释:
```text
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
```

**示例 2:**
输入: nums = `[1]`, k = `1`
输出: `[1]`

**提示：**
- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`
- `1 <= k <= nums.length`

**解法**
```java
class Solution {
    /* 
     * 单调队列：按 nums 值单调递减存储。
     * 因此每个窗口的最大值始终是 nums[queue[front]]。
     * 当窗口右移时，先移除已经离开窗口的队头下标，再从队尾删除不可能成为后续最大值的较小元素。
     *
     * 时间复杂度：O(n)
     * 说明：每个下标最多入队一次、出队一次，整体线性遍历数组。
     *
     * 空间复杂度：O(n)
     * 说明：queue 最多存放 n 个下标，答案数组 ans 需要 O(n-k+1) 空间。
     */
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] queue = new int[n], ans = new int[n - k + 1];
        int front = 0, tail = -1;

        // 先处理第一个窗口，建立从队头到队尾单调递减的下标队列。
        for (int i = 0; i < k; i++) {
            while (front <= tail && nums[queue[tail]] <= nums[i])
                tail--;
            queue[++tail] = i;
        }
        ans[0] = nums[queue[front]];
        
        for (int i = k; i < n; i++) {
            // 队头下标已经不在当前窗口 [i-k+1, i] 内，需要弹出。
            if (queue[front] == i - k)
                front++;
            // 移除队尾所有不大于当前值的元素，它们不会再成为后续窗口最大值。
            while (front <= tail && nums[queue[tail]] <= nums[i])
                tail--;
            queue[++tail] = i;
            ans[i - k + 1] = nums[queue[front]];
        }
        return ans;
    }
}
```
