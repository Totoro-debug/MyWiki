**原题链接**：[3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[哈希表](https://leetcode.cn/tag/hash-table/) [字符串](https://leetcode.cn/tag/string/) [滑动窗口](https://leetcode.cn/tag/sliding-window/)

**描述**：

- 给定一个字符串 `s`，请你找出其中不含有重复字符的**最长子串**的长度。
- **子字符串**是字符串中连续的**非空**字符序列。

**示例 1：**
输入：s = "abcabcbb"
输出：3
解释：因为无重复字符的最长子串是 `"abc"`，所以其长度为 3。注意 `"bca"` 和 `"cab"` 也是正确答案。

**示例 2：**
输入：s = "bbbbb"
输出：1
解释：因为无重复字符的最长子串是 `"b"`，所以其长度为 1。

**示例 3：**
输入：s = "pwwkew"
输出：3
解释：因为无重复字符的最长子串是 `"wke"`，所以其长度为 3。请注意，你的答案必须是**子串**的长度，`"pwke"` 是一个**子序列**，不是子串。

**提示：**
- `0 <= s.length <= 5 * 10^4`
- `s` 由英文字母、数字、符号和空格组成


**解法**
```java
class Solution {
    /*
     * 滑动窗口 + 布尔数组判重。
     * 1. 用 [l, r] 维护一个不含重复字符的窗口，右指针不断向右扩展；
     * 2. 如果当前字符 ch 重复出现，先用当前窗口长度更新 max。
     * 3. 不断移动左指针，直到窗口内不再包含重复字符 ch。
     *
     * 时间复杂度：O(n)
     * 每个字符最多被右指针加入窗口一次、被左指针移出窗口一次，总操作次数与字符串长度成正比。
     *
     * 空间复杂度：O(1)
     * 使用长度为 128 的布尔数组记录字符是否在窗口中出现，额外空间为常数级。
     */
    public int lengthOfLongestSubstring(String s) {
        boolean[] has = new boolean[128];
        char[] str = s.toCharArray();
        int l = 0, r = 0, n = str.length;
        int max = 0;
        for (char ch; r < n; r++) {
            ch = str[r];
            if (has[ch]) {
                // 当前字符重复，先用当前窗口长度更新答案
                max = Math.max(max, r - l);
                // 不断收缩左边界，直到窗口内不再包含重复字符 ch
                while (has[ch] && l < r) {
                    has[str[l]] = false;
                    l++;
                }
            }
            has[ch] = true;
        }
        // 循环结束后，比较最后一个窗口
        max = Math.max(max, r - l);
        return max;
    }
}
```
