**原题链接**：[438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[哈希表](https://leetcode.cn/tag/hash-table/)[字符串](https://leetcode.cn/tag/string/)[滑动窗口](https://leetcode.cn/tag/sliding-window/)

**描述**：给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 异位词 的子串，返回这些子串的起始索引。不考虑答案输出顺序。

**示例 1:**
输入: s = "cbaebabacd", p = "abc"
输出: `[0,6]`
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

**示例 2:**
输入: s = "abab", p = "ab"
输出: `[0,1,2]`
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。

**提示：**
- `1 <= s.length, p.length <= 3 * 104`
- `s` 和 `p` 仅包含小写字母

**解法**
```java
class Solution {
    /* 
     * 滑动窗口 + 字符计数。
     * need 记录 p 中每个字符的目标出现次数，has 记录当前窗口中的字符出现次数。
     * 窗口 [l, r) 在 s 上向右移动；当某个字符出现次数超过 need 时，持续右移 l 收缩窗口。
     * 只有窗口长度等于 p.length 且所有字符计数一致时，当前 l 才是一个异位词起点。
     *
     * 时间复杂度：O(m + n + (n-m)*k)
     * 说明：遍历 p，遍历 s。check() 最多执行 n-m 次，check() 复杂度与字符集大小相关。
     *
     * 空间复杂度：O(k)
     * 说明：has 和 need 占用空间和字符集相关。
     */
    public List<Integer> findAnagrams(String s, String p) {
        char[] str = s.toCharArray(), ptr = p.toCharArray();
        int[] has = new int[128], need = new int[128];
        for (char ch : ptr) {
            need[ch]++;
        }

        List<Integer> ans = new LinkedList();
        int n = str.length, m = ptr.length;
        int l = 0, r = 0;
        while (r < n) {
            // 窗口大小 = m 且 check 通过，当前起始点加入答案。
            if (r - l == m && check(has, need)) {
                ans.add(l);
            }

            char ch = str[r++];
            // 新加入字符后若超过目标次数，说明窗口不可能匹配，需要收缩左边界。
            if (++has[ch] > need[ch]) {
                while (l < r && has[ch] > need[ch]) {
                    has[str[l++]]--;
                }
            }
        }
        if (r - l == m && check(has, need)) {
            ans.add(l);
        }
        return ans;
    }

    boolean check(int[] has, int[] need) {
        for (int i = 'a'; i <= 'z'; i++) {
            if (has[i] != need[i])
                return false;
        }
        return true;
    }
}
```
