**原题链接**：[48. 旋转图像](https://leetcode.cn/problems/rotate-image/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[数组](https://leetcode.cn/tag/array/) [数学](https://leetcode.cn/tag/math/) [矩阵](https://leetcode.cn/tag/matrix/)

**描述**：

- 给定一个 `n x n` 的二维矩阵 `matrix` 表示一个图像。
- 请将图像顺时针旋转 `90` 度。
- 你必须在原地旋转图像，这意味着需要直接修改输入的二维矩阵。
- 请不要使用另一个二维矩阵来旋转图像。

**示例 1：**
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]

**示例 2：**
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]

**提示：**
- n == matrix.length == matrix[i].length
- 1 <= n <= 20
- -1000 <= matrix[i][j] <= 1000


**解法**
```java
/*
 * 原地分层旋转：按矩阵外圈到内圈逐层处理，每次完成四个对称位置的循环交换。
 * 1. 第 t 层的边界为 t 到 n - 1 - t，只需要处理上边的一段元素。
 * 2. 对于上边位置 (t, i)，依次把左、下、右、上四个位置的值顺时针搬移。
 * 3. 每组四个元素只使用一个临时变量完成交换，因此满足原地旋转要求。
 *
 * 时间复杂度：O(n²)
 * 矩阵中的每个元素都会被访问并交换一次量级，其中 n 为矩阵边长。
 *
 * 空间复杂度：O(1)
 * 只使用 n、step、tmp 等常量级额外变量。
 */
public void rotate(int[][] matrix) {
	int n = matrix.length;
	int step = n >> 1;
	for (int t = 0; t < step; t++) {
		for (int i = t; i < n - 1 - t; i++) {
			int tmp = matrix[t][i];
			matrix[t][i] = matrix[n - 1 - i][t];
			matrix[n - 1 - i][t] = matrix[n - 1 - t][n - 1 - i];
			matrix[n - 1 - t][n - 1 - i] = matrix[i][n - 1 - t];
			matrix[i][n - 1 - t] = tmp;
		}
	}
}
```
