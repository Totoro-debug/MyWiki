**原题链接**：[73. 矩阵置零](https://leetcode.cn/problems/set-matrix-zeroes/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[数组](https://leetcode.cn/tag/array/) [哈希表](https://leetcode.cn/tag/hash-table/) [矩阵](https://leetcode.cn/tag/matrix/)

**描述**：

- 给定一个 `m x n` 的矩阵 `matrix`。
- 如果一个元素为 `0`，则将其所在行和列的所有元素都设为 `0`。
- 请使用原地算法完成操作。

**示例 1：**
输入：matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[1,0,1],[0,0,0],[1,0,1]]

**示例 2：**
输入：matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出：[[0,0,0,0],[0,4,5,0],[0,3,1,0]]

**提示：**
- m == matrix.length
- n == matrix[0].length
- 1 <= m, n <= 200
- -2^31 <= matrix[i][j] <= 2^31 - 1

**进阶：**
- 一个直观的解决方案是使用 O(mn) 的额外空间，但这并不是一个好的解决方案。
- 一个简单的改进方案是使用 O(m + n) 的额外空间。
- 你能想出一个仅使用常量空间的解决方案吗？


**解法**
```java
/*
 * 原地标记：使用第一行和第一列作为标记数组，记录哪些行、列需要置零。
 * 1. 先扫描矩阵：若 matrix[i][j] 为 0，则用 matrix[i][0] 标记第 i 行，用 matrix[0][j] 标记第 j 列。
 * 2. 第一列本身会被用作行标记，因此额外用 hcol 记录第一列是否原本需要置零。
 * 3. 再从下往上回填矩阵，避免第一行/第一列的标记在过早置零后影响尚未处理的元素。
 * 4. 每行末尾根据 hcol 单独处理第一列。
 *
 * 时间复杂度：O(mn)
 * 需要完整扫描矩阵两次，其中 m 为矩阵行数，n 为矩阵列数。
 *
 * 空间复杂度：O(1)
 * 仅使用 hcol 等常量级额外变量，标记信息复用矩阵自身的第一行和第一列。
 */
public void setZeroes(int[][] matrix) {
	int m = matrix.length, n = matrix[0].length;
	boolean hcol = false;
	for (int i = 0; i < m; i++) {
		if (matrix[i][0] == 0)
			hcol = true;

		for (int j = 1; j < n; j++) {
			if (matrix[i][j] == 0)
				matrix[i][0] = matrix[0][j] = 0;
		}
	}

	for (int i = m - 1; i >= 0; i--) {
		for (int j = 1; j < n; j++) {
			if (matrix[i][0] == 0 || matrix[0][j] == 0)
				matrix[i][j] = 0;
		}
		if (hcol)
			matrix[i][0] = 0;
	}
}
```
