**原题链接**：[41. 缺失的第一个正数](https://leetcode.cn/problems/first-missing-positive/description/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[数组](https://leetcode.cn/tag/array/)[哈希表](https://leetcode.cn/tag/hash-table/)

**描述**：
- 给你一个未排序的整数数组 `nums`，请你找出其中没有出现的最小的正整数。
- 你必须实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。

**示例 1：**
输入：`nums = [1,2,0]`
输出：`3`
解释：范围 `[1,2]` 中的数字都在数组中。

**示例 2：**
输入：`nums = [3,4,-1,1]`
输出：`2`
解释：`1` 在数组中，但 `2` 没有。

**示例 3：**
输入：`nums = [7,8,9,11,12]`
输出：`1`
解释：最小的正整数 `1` 没有出现。

**提示：**
- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`


**解法**

```java
/*
 * 原地哈希 / 置换归位
 * 1. 缺失的第一个正数一定在 [1, n + 1] 范围内，因此只需要关注 [1, n] 中的数。
 * 2. 遍历数组，将值 num 放到下标 num - 1 的位置，使 nums[i] 尽量等于 i + 1。
 * 3. 遇到已经归位、非正数、超过 n、或目标位置已有相同值的元素时跳过，避免无效交换和死循环。
 * 4. 归位完成后，再从 1 开始扫描，第一个 nums[x - 1] != x 的 x 就是答案。
 */

/*
 * 时间复杂度：O(n)
 * 说明：每个有效数字最多被交换到正确位置一次，归位遍历和最终扫描都为线性时间。
 *
 * 空间复杂度：O(1)
 * 说明：直接在原数组上交换元素，只使用常数个额外变量。
 */
public int firstMissingPositive(int[] nums) {
	int n = nums.length, num;
	for (int i = 0; i < n;) {
		if ((num = nums[i]) == i + 1 || num <= 0 || num > n || num == nums[num - 1])
			i++;
		else
			swap(nums, i, num - 1);
	}
	
	num = 1;
	while (num <= n && nums[num - 1] == num)
		num++;
	return num;
}

void swap(int[] nums, int l, int r) {
	int tmp = nums[l];
	nums[l] = nums[r];
	nums[r] = tmp;
}
```
