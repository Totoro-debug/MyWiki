**原题链接**：[240. 搜索二维矩阵 II](https://leetcode.cn/problems/search-a-2d-matrix-ii/description/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[数组](https://leetcode.cn/tag/array/) [二分查找](https://leetcode.cn/tag/binary-search/) [分治](https://leetcode.cn/tag/divide-and-conquer/) [矩阵](https://leetcode.cn/tag/matrix/)

**描述**：

- 编写一个高效的算法来搜索 `m x n` 矩阵 `matrix` 中的一个目标值 `target`。
- 该矩阵具有以下特性：
  - 每行的元素从左到右升序排列。
  - 每列的元素从上到下升序排列。

**示例 1：**
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 5
输出：true

**示例 2：**
输入：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]], target = 20
输出：false

**提示：**
- m == matrix.length
- n == matrix[i].length
- 1 <= n, m <= 300
- -10^9 <= matrix[i][j] <= 10^9
- 每行的所有元素从左到右升序排列
- 每列的所有元素从上到下升序排列
- -10^9 <= target <= 10^9


**解法**
```java
/*
 * Z 字形搜索：从右上角出发，利用矩阵行列递增的性质逐步缩小搜索范围。
 * 1. 右上角元素是当前行剩余元素中的最大值，也是当前列剩余元素中的最小值。
 * 2. 若当前值等于 target，直接返回 true。
 * 3. 若当前值小于 target，说明当前行左侧元素更小，不可能命中，向下移动一行。
 * 4. 若当前值大于 target，说明当前列下方元素更大，不可能命中，向左移动一列。
 *
 * 时间复杂度：O(m + n)
 * 每次移动都会排除一行或一列，最多移动 m + n 次，其中 m 为矩阵行数，n 为矩阵列数。
 *
 * 空间复杂度：O(1)
 * 仅使用 i、j、tmp 等常量级额外变量。
 */
public boolean searchMatrix(int[][] matrix, int target) {
	int m = matrix.length, n = matrix[0].length;
	int i = 0, j = n - 1, tmp;
	while (i < m && j >= 0) {
		if ((tmp = matrix[i][j]) == target)
			return true;
		else if (tmp < target)
			i++;
		else
			j--;
	}
	return false;
}
```
