**原题链接**：[19. 删除链表的倒数第 N 个结点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[链表](https://leetcode.cn/tag/linked-list/) [双指针](https://leetcode.cn/tag/two-pointers/)

**描述**：

- 给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

**示例 1：**
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]

**示例 2：**
输入：head = [1], n = 1
输出：[]

**示例 3：**
输入：head = [1,2], n = 1
输出：[1]

**提示：**
- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`


**解法**
```java
/*
 * 双指针
 * 1. 先让 fast 指针向前移动 n 步，使 fast 与 slow 之间保持 n 个节点的距离。
 * 2. 使用虚拟头节点 h 统一处理删除头节点的情况，slow 从 h 开始移动。
 * 3. fast 与 slow 同步向后移动，直到 fast 到达链表末尾，此时 slow.next 即为倒数第 n 个节点。
 * 4. 通过 slow.next = slow.next.next 跳过目标节点，完成删除。
 */
/*
 * 时间复杂度：O(sz)
 * 说明：fast 和 slow 都只沿链表单向移动，每个节点最多被访问常数次。
 *
 * 空间复杂度：O(1)
 * 说明：只使用 fast、slow 和虚拟头节点等常数额外空间。
 */
public ListNode removeNthFromEnd(ListNode head, int n) {
	ListNode fast = head, slow;
	while (n-- > 0) {
		fast = fast.next;
	}
	ListNode h = new ListNode(0, head);
	slow = h;
	while (fast != null) {
		slow = slow.next;
		fast = fast.next;
	}
	slow.next = slow.next.next;
	return h.next;
}
```
