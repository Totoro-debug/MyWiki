**原题链接**：[234. 回文链表](https://leetcode.cn/problems/palindrome-linked-list/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[栈](https://leetcode.cn/tag/stack/) [递归](https://leetcode.cn/tag/recursion/) [链表](https://leetcode.cn/tag/linked-list/) [双指针](https://leetcode.cn/tag/two-pointers/)

**描述**：

- 给你一个单链表的头节点 `head` ，请你判断该链表是否为回文链表。如果是，返回 `true` ；否则，返回 `false` 。

**示例 1：**
输入：head = [1,2,2,1]
输出：true

**示例 2：**
输入：head = [1,2]
输出：false

**提示：**
- 链表中节点数目在范围 `[1, 10^5]` 内
- `0 <= Node.val <= 9`

**进阶：**
- 你能否用 `O(n)` 时间复杂度和 `O(1)` 空间复杂度解决此题？


**解法**
```java
/*
 * 双指针 + 反转后半段链表
 * 1. 使用快慢指针定位前半段链表的尾节点 slow。
 * 2. 反转 slow.next 开始的后半段链表，并断开前后两段。
 * 3. 从头节点和反转后的后半段头节点同步遍历，逐一比较节点值。
 */

/*
 * 时间复杂度：O(n)
 * 说明：快慢指针遍历约半条链表，反转后半段并再次比较，总访问次数与节点数 n 线性相关。
 *
 * 空间复杂度：O(1)
 * 说明：只使用 slow、fast、p、np 等常数个指针变量，反转链表在原链表上原地完成。
 */
public boolean isPalindrome(ListNode head) {
	ListNode slow = head, fast = head.next;
	while (fast != null && fast.next != null) {
		slow = slow.next;
		fast = fast.next.next;
	}
	fast = reverse(slow.next);
	slow.next = null;
	slow = head;
	while (fast != null && slow.val == fast.val) {
		slow = slow.next;
		fast = fast.next;
	}
	return fast == null;
}

ListNode reverse(ListNode head) {
	ListNode h = new ListNode(), p = head, np;
	while (p != null) {
		np = p.next;
		p.next = h.next;
		h.next = p;
		p = np;
	}
	return h.next;
}
```
