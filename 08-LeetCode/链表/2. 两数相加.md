**原题链接**：[2. 两数相加](https://leetcode.cn/problems/add-two-numbers/description/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[链表](https://leetcode.cn/tag/linked-list/) [数学](https://leetcode.cn/tag/math/) [递归](https://leetcode.cn/tag/recursion/)

**描述**：

- 给你两个 非空 的链表，表示两个非负的整数。
- 它们每位数字都是按照 逆序 的方式存储的，并且每个节点只能存储 一位 数字。
- 请你将两个数相加，并以相同形式返回一个表示和的链表。
- 你可以假设除了数字 `0` 之外，这两个数都不会以 `0` 开头。

**示例 1：**
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807

**示例 2：**
输入：l1 = [0], l2 = [0]
输出：[0]

**示例 3：**
输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出：[8,9,9,9,0,0,0,1]

**提示：**
- 每个链表中的节点数在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`
- 题目数据保证列表表示的数字不含前导零


**解法**
```java
/*
 * 核心算法：链表模拟竖式加法（原地复用节点）。
 * 1. 同时遍历 l1 和 l2，将当前位与进位 carry 相加，并把个位结果写回 l1 当前节点。
 * 2. 当 l1 先结束而 l2 仍有剩余时，将 l2 剩余部分接到结果链表尾部，继续处理进位。
 * 3. 对较长链表的剩余节点继续传播进位；若最终仍有进位，则追加值为 1 的新节点。
 */

/*
 * 时间复杂度：O(max(m, n))
 * 说明：m、n 分别为两个链表长度，每个节点最多被访问一次。
 *
 * 空间复杂度：O(1)
 * 说明：除最终进位可能新增一个节点外，只使用常数个额外变量，并原地复用输入链表节点。
 */
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
	int carry = 0, sum;
	ListNode tail = l1, head = l1;
	while (l1 != null && l2 != null) {
		sum = l1.val + l2.val + carry;
		if (sum >= 10) {
			carry = 1;
			l1.val = sum - 10;
		} else {
			carry = 0;
			l1.val = sum;
		}

		tail = l1;
		l1 = l1.next;
		l2 = l2.next;
	}
	
	if (l2 != null)
		tail.next = l2;

	while (tail.next != null && carry == 1) {
		sum = tail.next.val + carry;
		if (sum >= 10) {
			carry = 1;
			tail.next.val = sum - 10;
		} else {
			carry = 0;
			tail.next.val = sum;
		}

		tail = tail.next;
	}
	if (carry == 1)
		tail.next = new ListNode(1);

	return head;
}
```
