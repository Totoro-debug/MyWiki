**原题链接**：[21. 合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/description/)

**标签**：[递归](https://leetcode.cn/tag/recursion/) [链表](https://leetcode.cn/tag/linked-list/)

**描述**：

- 将两个升序链表合并为一个新的 升序 链表并返回。
- 新链表是通过拼接给定的两个链表的所有节点组成的。

**示例 1：**
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]

**示例 2：**
输入：l1 = [], l2 = []
输出：[]

**示例 3：**
输入：l1 = [], l2 = [0]
输出：[0]

**提示：**
- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `l1` 和 `l2` 均按 非递减顺序 排列


**解法**
```java
/*
 * 双指针
 * 1. 使用虚拟节点 h 作为合并后链表的虚拟头节点，tail 始终指向结果链表尾部。
 * 2. 同时遍历 list1 和 list2，每次选择当前值较小的节点接到 tail 后面。
 * 3. 当其中一个链表遍历结束后，直接把另一个链表剩余部分接到 tail 后面。
 */
/*
 * 时间复杂度：O(m + n)
 * 说明：m 和 n 分别为两个链表长度，每个节点最多被访问和接入一次。
 *
 * 空间复杂度：O(1)
 * 说明：只使用常数个指针变量，复用原链表节点，不额外创建与输入规模相关的新链表。
 */
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
	if (list1 == null)
		return list2;
	if (list2 == null)
		return list1;

	ListNode h = new ListNode(), tail = h;
	while (list1 != null && list2 != null) {
		if (list1.val < list2.val) {
			tail = tail.next = list1;
			list1 = list1.next;
		} else {
			tail = tail.next = list2;
			list2 = list2.next;
		}
	}
	if (list1 != null)
		tail.next = list1;
	if (list2 != null)
		tail.next = list2;
	return h.next;
}
```
