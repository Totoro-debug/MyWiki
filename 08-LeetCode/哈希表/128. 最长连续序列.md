**原题链接**：[128. 最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/description/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[并查集](https://leetcode.cn/tag/union-find/) [数组](https://leetcode.cn/tag/array/) [哈希表](https://leetcode.cn/tag/hash-table/)

**描述**：

- 给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。
- 请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1：**
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。

**示例 2：**
输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9

**示例 3：**
输入：nums = [1,0,1,2]
输出：3

**提示：**
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`


**解法**
```java
class Solution {
    /*
     * 哈希去重 + 连续序列：
     * 1. 使用哈希集合去重，只从连续序列起点开始扩展，减少不必要的遍历。
     * 2. 遍历集合，如果集合种不存在 num-1，说明 num 是某段连续序列的起点，
     * 3. 此时不断向右查找 num + 1、num + 2 ...，即可得到这一段连续序列的长度。
     *
     * 时间复杂度：O(n)
     * 先遍历数组完成去重，再遍历哈希集合寻找连续序列起点；
     * 每个元素最多只会被判断和扩展常数次，因此总时间复杂度为 O(n)。
     *
     * 空间复杂度：O(n)
     * 主要来自哈希集合存储数组中的所有不同元素。
     */
    public int longestConsecutive(int[] nums) {
        if (nums.length <= 1) {
            return nums.length;
        }
		
		// 哈希集合去重
        Set<Integer> set = new HashSet<>(nums.length, 1);
        for (int num : nums)
            set.add(num);

        int max = 1;
        for (int num : set) {
            // 只有当前数字没有前驱时，才把它当作连续序列起点
            if (set.contains(num - 1)) 
                continue;

			// 从起点开始向右扩展，计算这段连续区间的长度
            int r = num + 1;
            while (set.contains(r)) r++; 
            max = Math.max(max, r - num);
        }
        return max;
    }
}
```
