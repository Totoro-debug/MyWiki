**原题链接**：[560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/description/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[数组](https://leetcode.cn/tag/array/) [哈希表](https://leetcode.cn/tag/hash-table/) [前缀和](https://leetcode.cn/tag/prefix-sum/)

**描述**：

- 给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的子数组的个数。
- 子数组是数组中元素的连续非空序列。

**示例 1：**
输入：nums = [1,1,1], k = 2
输出：2

**示例 2：**
输入：nums = [1,2,3], k = 3
输出：2

**提示：**
- 1 <= nums.length <= 2 * 10^4
- -1000 <= nums[i] <= 1000
- -10^7 <= k <= 10^7


**解法**
```java
class Solution {
    /* 
     * 前缀和 + 哈希表。
     * 设当前前缀和为 sum，若之前存在前缀和 pre = sum - k，
     * 则从该位置之后到当前位置的子数组和为 k。
     * 用哈希表统计每个前缀和出现次数，边遍历边累加答案。
     *
     * 时间复杂度：O(n)
     * 说明：只遍历数组一次，每次哈希表查询和更新 O(1)。
     *
     * 空间复杂度：O(n)
     * 说明：最坏情况下每个位置的前缀和都不同，哈希表需要存储 O(n) 个前缀和。
     */
    public int subarraySum(int[] nums, int k) {
        int n = nums.length;
        // key 为前缀和，value 为该前缀和在当前遍历位置之前出现的次数
        Map<Integer, Integer> map = new HashMap<>();
        // 空前缀和出现 1 次，用于统计从下标 0 开始、和为 k 的子数组
        map.put(0, 1);
        int sum = 0, ans = 0;
        for (int num : nums) {
            sum += num;
            // 若存在 sum - k，则这些历史前缀和都能与当前前缀和组成和为 k 的子数组
            ans += map.getOrDefault(sum - k, 0);
            map.put(sum, map.getOrDefault(sum, 0) + 1);
        }
        return ans;
    }
}
```
