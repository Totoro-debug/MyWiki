**原题链接**：[49. 字母异位词分组](https://leetcode.cn/problems/group-anagrams/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[数组](https://leetcode.cn/tag/array/)[哈希表](https://leetcode.cn/tag/hash-table/)[字符串](https://leetcode.cn/tag/string/)[排序](https://leetcode.cn/tag/sorting/)

**描述**：给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

**示例 1:**
输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出: `[["bat"],["nat","tan"],["ate","eat","tea"]]`
解释：
- 在 strs 中没有字符串可以通过重新排列来形成 `"bat"`。
- 字符串 `"nat"` 和 `"tan"` 是字母异位词，因为它们可以重新排列以形成彼此。
- 字符串 `"ate"` ，`"eat"` 和 `"tea"` 是字母异位词，因为它们可以重新排列以形成彼此。

**示例 2:**
输入: strs = [""]
输出: `[[""]]`

**示例 3:**
输入: strs = ["a"]
输出:`[["a"]]`

**提示：**
- `1 <= strs.length <= 104`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

**解法**
```java
class Solution {
    /*
     * 哈希表 + 排序。
     * 字母异位词排序后会得到相同字符串，因此可以把排序后的字符串作为分组 key，
     * 将原字符串加入对应的 value 列表中，最后返回哈希表中的所有分组。
     *
     * 时间复杂度：O(n × k log k)
     * 其中 n 是字符串数量，k 是 strs 中字符串的最大长度。
     * 每个字符串都需要排序后，才能确定对应的分组。
     *
     * 空间复杂度：O(n × k)
     * 哈希表需要保存每个分组以及分组中的全部字符串。
     */
    public List<List<String>> groupAnagrams(String[] strs) {
        List<List<String>> ans = new LinkedList<>();
        // key 是排序后的字符串，value 是所有属于该异位词分组的原字符串
        HashMap<String, List<String>> map = new HashMap<>(512);
        for (String str : strs) {
            char[] chs = str.toCharArray();
            Arrays.sort(chs);
            // 将当前字符串排序，得到该异位词分组的统一签名
            String zstr = String.valueOf(chs);
            List<String> list = null;
            if ((list = map.get(zstr)) == null) {
                list = new LinkedList<>();
                map.put(zstr, list);
            }
            list.add(str);
        }
        return new ArrayList<>(map.values());
    }
}
```
