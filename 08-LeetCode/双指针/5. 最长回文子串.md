**原题链接**：[5. 最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/)

**标签**：[双指针](https://leetcode.cn/tag/two-pointers/)、[字符串](https://leetcode.cn/tag/string/)、[动态规划](https://leetcode.cn/tag/dynamic-programming/)

**描述**：

- 给你一个字符串 `s`。
- 找到 `s` 中最长的回文子串。
- 回文串是正着读和反着读都一样的字符串。

**示例 1：**
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。

**示例 2：**
输入：s = "cbbd"
输出："bb"

**提示：**
- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成


**解法**
```java
/*
 * 核心算法：中心扩展 + 双指针。
 * 1. 枚举每个可能的回文中心，分别处理奇数长度中心 `(i, i)` 和偶数长度中心 `(i, i + 1)`。
 * 2. 对每个中心使用左右指针向两侧扩展，只要左右字符相等，就继续扩大当前回文范围。
 * 3. 扩展结束后，根据 `r - l - 1` 得到当前回文长度，并记录最长回文的起点和长度。
 * 4. 最后通过 `substring(start, start + max)` 截取最长回文子串。
 *
 * 时间复杂度：O(n^2)
 * 说明：最多枚举 2n 个中心，每次中心扩展在最坏情况下可能扫描 O(n) 个字符。
 *
 * 空间复杂度：O(1)
 * 说明：只使用左右指针、起点和最长长度等常数级额外变量。
 */
public String longestPalindrome(String s) {
	int n = s.length(), max = 0, start = 0;
	if (n == 1)
		return s;
	for (int i = 0; i < n - 1; i++) {
		for (int k = 0; k < 2; k++) {
			int l = i, r = i + k;
			while (l >= 0 && r < n && s.charAt(l) == s.charAt(r)) {
				l--;
				r++;
			}
			if (r - l - 1 > max) {
				max = r - l - 1;
				start = l + 1;
			}
		}
	}
	return s.substring(start, start + max);
}
```
