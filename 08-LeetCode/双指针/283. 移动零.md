**原题链接**：[283. 移动零](https://leetcode.cn/problems/move-zeroes/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[数组](https://leetcode.cn/tag/array/)、[双指针](https://leetcode.cn/tag/two-pointers/)

**描述**：

- 给定一个整数数组 `nums`，请将所有 `0` 移动到数组末尾。
- 同时需要保持非零元素的相对顺序不变。
- 必须在**原数组上操作**，不能额外拷贝数组。

**示例 1：**
输入：nums = [0,1,0,3,12]
输出：[1,3,12,0,0]
解释：将所有 0 移到末尾后，非零元素 1、3、12 的相对顺序保持不变。

**示例 2：**
输入：nums = [0]
输出：[0]

**提示：**
- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

**补充说明：**
- 进阶要求是尽量减少操作次数。


**解法**
```java
class Solution {
    /*
     * 双指针：l 指向下一个非零元素应该放置的位置，r 从左到右扫描数组。
     * 当 nums[r] != 0 时: 如果 l < r，说明中间存在 0，将 nums[r] 移动到 l，并将 r 处置为 0。
     *
     * 时间复杂度：O(n)
     * 说明：r 指针只遍历数组一次，每个元素最多被访问和处理一次。
     *
     * 空间复杂度：O(1)
     * 说明：只使用 l、r、n 等常数级变量，并且在原数组上完成修改。
     */
    public void moveZeroes(int[] nums) {
        int n = nums.length, l = 0, r = 0;
        while (r < n) {
            if (nums[r] != 0) {
                if (l < r) {
                    // 将当前非零元素前移到下一个可放置位置，并把原位置补为 0
                    nums[l] = nums[r];
                    nums[r] = 0;
                }
                // l 始终指向下一个非零元素应该写入的位置
                l++;
            }
            r++;
        }
    }
}
```
