**原题链接**：[15. 三数之和](https://leetcode.cn/problems/3sum/description/)

**标签**：[数组](https://leetcode.cn/tag/array/)、[双指针](https://leetcode.cn/tag/two-pointers/)、[排序](https://leetcode.cn/tag/sorting/)

**描述**：

- 给定一个整数数组 `nums`。
- 判断 `nums` 中是否存在三个元素 `a`、`b`、`c`，使得 `a + b + c == 0`。
- 找出所有和为 `0` 且不重复的三元组。
- 注意：答案中不可以包含重复的三元组。

**示例 1：**
输入：nums = [-1,0,1,2,-1,-4]
输出：`[[-1,-1,2],[-1,0,1]]`
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0。
不同的三元组是 `[-1,0,1]` 和 `[-1,-1,2]`。
注意，输出的顺序和三元组的顺序并不重要。

**示例 2：**
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 `0`。

**示例 3：**
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 `0`。

**提示：**
- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

**解法**
```java
/*
 * 核心算法：排序 + 双指针。
 * 1. 先对数组排序，使三元组可以按非降序枚举，并方便跳过重复值。
 * 2. 固定第一个数 x，再在右侧区间中枚举第二个数 y。
 * 3. 第三个数 z 由 0 - x - y 唯一确定，通过右指针 k 从右向左收缩寻找 z。
 * 4. 对固定的 x 和 y 分别跳过重复值，保证答案中不包含重复三元组。
 * 5. 因为数组已排序，当 x > 0 或 z < 0 时，可以提前停止无效搜索。
 *
 * 时间复杂度：O(n^2)
 * 说明：排序需要 O(n log n)，外层固定 x，内层通过 j 枚举并配合 k 单调左移，整体主导为 O(n^2)。
 *
 * 空间复杂度：O(log n)
 * 说明：除返回答案外，只使用常数级变量；Java 的 Arrays.sort 对基本类型数组通常需要 O(log n) 递归栈空间。
 */
public List<List<Integer>> threeSum(int[] nums) {
	List<List<Integer>> ans = new LinkedList<>();
	Arrays.sort(nums);

	int n = nums.length;
	int x, y, z;

	// 固定第一个数 x；若 x 已经大于 0，后续三数之和不可能为 0。
	for (int i = 0; i < n - 2 && (x = nums[i]) <= 0; i++) {
		// 跳过重复的 x，避免生成重复三元组。
		if (i > 0 && nums[i - 1] == x)
			continue;

		// j 枚举第二个数 y，k 从右侧寻找唯一目标值 z。
		for (int j = i + 1, k = n - 1; j < n - 1 && (z = -x - (y = nums[j])) >= 0 && nums[k] >= 0; j++) {
			// 跳过重复的 y；x 和 y 确定后，z 也唯一确定。
			if (j > i + 1 && nums[j - 1] == y)
				continue;

			// 数组有序，若 nums[k] 偏大，则持续左移 k 缩小第三个数。
			while (j < k && nums[k] > z)
				k--;

			if (j < k && nums[k] == z) {
				ans.add(List.of(x, y, z));
			}
		}
	}
	return ans;
}
```
