**原题链接**：[11. 盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[数组](https://leetcode.cn/tag/array/)、[双指针](https://leetcode.cn/tag/two-pointers/)、[贪心](https://leetcode.cn/tag/greedy/)

**描述**：

- 给定一个长度为 `n` 的整数数组 `height`。
- 有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。
- 找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。
- 返回容器可以储存的最大水量。
- 说明：你不能倾斜容器。

**示例 1：**
输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
解释：图中垂直线代表输入数组 `[1,8,6,2,5,4,8,3,7]`。在此情况下，容器能够容纳水的最大值为 `49`。

**示例 2：**
输入：height = [1,1]
输出：1

**提示：**
- `n == height.length`
- `2 <= n <= 10^5`
- `0 <= height[i] <= 10^4`

**解法**
```java
class Solution {
    /*
     * 核心算法：双指针 + 贪心。
     * 1. 左右指针分别指向数组两端，当前容器宽度为 r - l，高度由较短的边决定。
     * 2. 每轮先用较短边计算当前面积并更新最大值。
     * 3. 因为移动较高的一侧只会让宽度变小且短板不变，无法得到更优解；
     *    所以每次移动较短的一侧，尝试寻找更高的短板。
     *
     * 时间复杂度：O(n)
     * 说明：左右指针最多各向中间移动 n 次，每个位置只会被访问常数次。
     *
     * 空间复杂度：O(1)
     * 说明：只使用指针、当前高度和最大面积等常数级额外变量。
     */
    public int maxArea(int[] height) {
        int n = height.length, l = 0, r = n - 1, lh, rh;
        int max = 0;
        while (l < r) {
            lh = height[l];
            rh = height[r];
            // 当前容器面积由左右边界距离和较短高度共同决定。
            if (lh < rh) {
                max = Math.max(max, lh * (r - l));
                // 左侧是短板，只有移动左指针才可能遇到更高的短板。
                l++;
            } else {
                max = Math.max(max, rh * (r - l));
                // 右侧是短板或两侧等高，移动右指针尝试扩大高度下限。
                r--;
            }
        }
        return max;
    }
}
```
