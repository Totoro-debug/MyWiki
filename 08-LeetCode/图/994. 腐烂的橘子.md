**原题链接**：[994. 腐烂的橘子](https://leetcode.cn/problems/rotting-oranges/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[广度优先搜索](https://leetcode.cn/tag/breadth-first-search/) [数组](https://leetcode.cn/tag/array/) [矩阵](https://leetcode.cn/tag/matrix/)

**描述**：

- 在给定的 `m x n` 网格 `grid` 中，每个单元格可以有以下三个值之一：
  - 值 `0` 代表空单元格；
  - 值 `1` 代表新鲜橘子；
  - 值 `2` 代表腐烂的橘子。
- 每分钟，腐烂的橘子会使上下左右四个方向相邻的新鲜橘子腐烂。
- 返回直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。
- 如果不可能使每个新鲜橘子都腐烂，返回 `-1`。

**示例 1：**
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4

**示例 2：**
输入：grid = [[2,1,1],[0,1,1],[1,0,1]]
输出：-1
解释：左下角的新鲜橘子永远不会腐烂，因为腐烂只会发生在上下左右四个方向。

**示例 3：**
输入：grid = [[0,2]]
输出：0
解释：因为一开始就没有新鲜橘子，所以答案为 0。

**提示：**
- m == grid.length
- n == grid[i].length
- 1 <= m, n <= 10
- grid[i][j] 为 `0`、`1` 或 `2`


**解法**
```java
/*
 * 多源广度优先搜索（BFS）：
 * 1. 先遍历网格，将所有初始腐烂橘子加入队列，作为 BFS 的多个起点；同时统计新鲜橘子数量。
 * 2. 按分钟分层扩散，每一层表示当前这一分钟内会继续腐烂相邻新鲜橘子的所有位置。
 * 3. 每腐烂一个新鲜橘子，就将其标记为 2 并减少新鲜橘子计数，避免重复入队。
 * 4. BFS 结束后，如果仍有新鲜橘子，说明存在无法被感染的位置，返回 -1；否则返回实际经过的分钟数。
 *
 * 时间复杂度：O(mn)
 * 其中 m、n 分别为网格的行数和列数；每个单元格最多被遍历、入队和出队一次。
 *
 * 空间复杂度：O(mn)
 * 队列在最坏情况下可能存放 O(mn) 个腐烂橘子位置；方向数组只占用常数空间。
 */
public int orangesRotting(int[][] grid) {
	int m = grid.length, n = grid[0].length, cnt = 0;
	final int[] dir = new int[] { -1, 0, 1, 0, -1 };
	Deque<int[]> queue = new LinkedList<>();
	for (int i = 0; i < m; i++)
		for (int j = 0; j < n; j++)
			if (grid[i][j] == 2)
				queue.offer(new int[] { i, j });
			else if (grid[i][j] == 1)
				cnt++;
	if (cnt == 0)
		return 0;

	int time = 0;
	while (!queue.isEmpty()) {
		int size = queue.size();
		while (size-- > 0) {
			int[] tmp = queue.remove();
			int x = tmp[0], y = tmp[1];
			for (int i = 0; i < 4; i++) {
				int xx = x + dir[i];
				int yy = y + dir[i + 1];
				if (xx >= 0 && yy >= 0 && xx < m && yy < n && grid[xx][yy] == 1) {
					queue.offer(new int[] { xx, yy });
					grid[xx][yy] = 2;
					cnt--;
				}
			}
		}
		time++;
	}
	return cnt == 0 ? time - 1 : -1;
}
```
