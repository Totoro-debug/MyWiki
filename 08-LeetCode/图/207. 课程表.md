**原题链接**：[207. 课程表](https://leetcode.cn/problems/course-schedule/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[深度优先搜索](https://leetcode.cn/tag/depth-first-search/) [广度优先搜索](https://leetcode.cn/tag/breadth-first-search/) [图](https://leetcode.cn/tag/graph/) [拓扑排序](https://leetcode.cn/tag/topological-sort/)

**描述**：

- 你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1`。
- 在选修某些课程之前需要一些先修课程。先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]`，表示如果要学习课程 `ai`，则必须先学习课程 `bi`。
- 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0`，你需要先完成课程 `1`。
- 请你判断是否可能完成所有课程的学习？如果可以，返回 `true`；否则，返回 `false`。

**示例 1：**
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：总共有 2 门课程。学习课程 1 之前，需要完成课程 0。这是可能的。

**示例 2：**
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：总共有 2 门课程。学习课程 1 之前，需要先完成课程 0；并且学习课程 0 之前，还应先完成课程 1。这是不可能的。

**提示：**
- 1 <= numCourses <= 2000
- 0 <= prerequisites.length <= 5000
- prerequisites[i].length == 2
- 0 <= ai, bi < numCourses
- prerequisites[i] 中的所有课程对互不相同


**解法**
```java
/* 
 * 拓扑排序（BFS / Kahn 算法）
 * 1. 将课程看作图中的节点，先修关系 [to, from] 表示 from -> to。
 * 2. 统计每门课的入度，并建立邻接表保存后继课程。
 * 3. 先把所有入度为 0 的课程加入队列，表示这些课程可以直接学习。
 * 4. 每学完一门课，就删除它指向的边；若后继课程入度降为 0，则加入队列。
 * 5. 如果最终学完的课程数等于 numCourses，说明不存在环，可以完成所有课程。
 */

/*
 * 时间复杂度：O(n + m)
 * 其中 n 为课程数 numCourses，m 为先修关系数 prerequisites.length；每个节点和每条边最多处理一次。
 *
 * 空间复杂度：O(n + m)
 * 邻接表需要存储所有边，入度数组和队列最多存储 n 个课程。
 */
List<List<Integer>> neighbers;
int[] indegree;
int num;

public boolean canFinish(int numCourses, int[][] prerequisites) {
	num = numCourses;
	indegree = new int[num];
	neighbers = new ArrayList<>(num);
	for (int i = 0; i < num; i++)
		neighbers.add(new LinkedList<>());

	for (int[] edge : prerequisites) {
		int to = edge[0], from = edge[1];
		indegree[to]++;
		neighbers.get(from).add(to);
	}

	return topo();
}

boolean topo() {
	int cnt = 0;
	Deque<Integer> queue = new LinkedList<>();
	for (int i = 0; i < num; i++) {
		if (indegree[i] == 0)
			queue.add(i);
	}

	while (!queue.isEmpty()) {
		int from = queue.poll();
		cnt++;
		for (int to : neighbers.get(from)) {
			if (--indegree[to] == 0)
				queue.add(to);
		}
	}
	return cnt == num;
}
```
