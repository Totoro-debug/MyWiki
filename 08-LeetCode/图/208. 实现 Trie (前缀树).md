**原题链接**：[208. 实现 Trie (前缀树)](https://leetcode.cn/problems/implement-trie-prefix-tree/description/?envType=study-plan-v2&envId=top-100-liked)

**标签**：[设计](https://leetcode.cn/tag/design/)[字典树](https://leetcode.cn/tag/trie/)[哈希表](https://leetcode.cn/tag/hash-table/)[字符串](https://leetcode.cn/tag/string/)

**描述**：Trie（发音类似 "try"）或者说前缀树，是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。

请你实现 Trie 类：
- `Trie()` 初始化前缀树对象。
- `void insert(String word)` 向前缀树中插入字符串 `word`。
- `boolean search(String word)` 如果字符串 `word` 在前缀树中，返回 `true`；否则，返回 `false`。
- `boolean startsWith(String prefix)` 如果之前已经插入的字符串 `word` 的前缀之一为 `prefix`，返回 `true`；否则，返回 `false`。

**示例 1:**
输入：
```text
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
```
输出：
```text
[null, null, true, false, true, null, true]
```
解释：
```text
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 True
trie.search("app");     // 返回 False
trie.startsWith("app"); // 返回 True
trie.insert("app");
trie.search("app");     // 返回 True
```

**提示：**
- `1 <= word.length, prefix.length <= 2000`
- `word` 和 `prefix` 仅由小写英文字母组成
- `insert`、`search` 和 `startsWith` 调用次数总计不超过 `3 * 10^4`

**解法**
```java
/*
 * 字典树（Trie）
 * 1. 每个节点用长度为 26 的数组保存下一层字符节点，字符下标由 ch - 'a' 得到。
 * 2. insert 按字符逐层创建或复用节点，遍历结束后用 isWord 标记一个完整单词。
 * 3. search 和 startsWith 都沿字符路径向下查找；区别是 search 还要求末尾节点被标记为完整单词。
 */

/*
 * 时间复杂度：insert、search、startsWith 均为 O(L)
 * 说明：L 为本次操作传入字符串或前缀的长度，每次只顺序访问每个字符一次。
 *
 * 空间复杂度：insert 最多新增 O(L) 个节点，search 和 startsWith 额外空间为 O(1)
 * 说明：整棵 Trie 的总空间为 O(T)，T 为所有已插入单词的字符总数；每个节点的 26 个子指针为常数规模。
 */
Trie[] sons = new Trie[26];
boolean isWord = false;

public Trie() { }

public void insert(String word) {
	char[] chs = word.toCharArray();
	Trie cur = this;

	for (int i = 0; i < chs.length; i++) {
		if (cur.sons[chs[i] - 'a'] == null) {
			cur.sons[chs[i] - 'a'] = new Trie();
		}
		cur = cur.sons[chs[i] - 'a'];
	}
	cur.isWord = true;
}

public boolean search(String word) {
	char[] chs = word.toCharArray();
	Trie cur = this;
	for (int i = 0; i < chs.length; i++) {
		if (cur.sons[chs[i] - 'a'] == null)
			return false;
		cur = cur.sons[chs[i] - 'a'];
	}
	return cur.isWord;
}

public boolean startsWith(String prefix) {
	char[] chs = prefix.toCharArray();
	Trie cur = this;
	for (int i = 0; i < chs.length; i++) {
		if (cur.sons[chs[i] - 'a'] == null)
			return false;
		cur = cur.sons[chs[i] - 'a'];
	}
	return true;
}
```
